# 0.2.17 驗證

Windows 原生 MediaPlayer 使用隔離的 20 秒靜音 MP3，18 項播放器檢查通過：實際播放及音訊時長、暫停跳播、音量由 100% 直接改至 50%、靜音／恢復、播放完畢重設；新增下載、下載中、已下載、設定及 AcoustID 頁面切換時，Source 仍為同一檔案，音訊位置繼續前進，計時器及播放狀態保持啟用。重建編輯頁面共用同一播放 session，顯示同步的進度及音量，自動選取正在試聽的歌曲。暫停時切換頁面不會自行播放。切換歌曲停止上一首；真正關閉主視窗會關閉音訊及計時器。測試 MP3 SHA256 不變。

Computer Use 在隔離的正常大小 Windows 視窗實際點擊播放、下載頁面、返回標籤編輯、設定及返回：歌曲由 24 秒繼續前進，返回後仍顯示暫停按鈕及目前位置。直接點擊音量軌道後顯示 50%，原生音量約 0.504；設定返回後仍保留此音量。再按暫停後，原生播放及計時器停止於約 2:00。測試使用 3 分鐘靜音 MP3，沒有操作使用者現有 App 或歌曲。已關閉隔離視窗。

檢查正常及較窄視窗的播放器畫面；控制項、時間與音量顯示沿用現有 UI。Core 84/84 測試通過。

AcoustID 核對回歸通過：同窗內部導覽、隱藏側欄、取消保留草稿及播放、不在預覽時寫入、僅寫入勾選欄位、封面選取、草稿合併及完整檔案復原。額外以真實 MediaPlayer 播放待修改 MP3，驗證按「套用所選標籤」後才釋放音訊並成功寫入。

資料夾保存回歸通過，涵蓋跨頁面及真正第二個程序重開、新增／改名歌曲、去重、下載歷史及 MP3 不變。

Windows Release 及 Android APK 建置成功；Android 22/22 單元測試通過。Android 僅同步版本號，未進行平板操作驗證。更新包保留 byte-identical NativeHost 及下載工具。
