# mp4/mp3 downloader 0.2.3

- 維持現有名稱；沒有重新命名或搬動使用者檔案。
- 新增下載網址及下載任務搜尋提示；任務搜尋涵蓋清單子項。
- MP4 使用圓圈播放圖示，MP3 使用簡潔連桿音符；功能圖示以藍、紫、青、綠、金色區分。
- Windows MP3 標籤欄位限制寬度，長文字不再撐闊整頁，窄視窗改上下排列。
- 設定改回原值後不再提示未儲存；Android 原有值比較保留。
- 新下載 MP3 封面：原影片圖片 → 同影片 ID 的 YouTube Music 資料 → MusicBrainz 可靠配對封面。接受長短邊比不超過 1.15、至少 100px 的近正方形，包含 233×217 和 475×500；不裁切、不拉伸、不強制縮成 500px。
- 封面查詢與 MusicBrainz 標籤改寫分開：關閉標籤改寫仍可查找專輯封面。歌曲中繼資料不會因此被改寫。
- 找不到可靠封面仍可完成下載並顯示「未找到專輯封面」，不使用長方形影片縮圖。
- 標籤頁新增批次「重新尋找封面」；不自動處理歷史檔案，查無結果時保留原封面。保護已標記為手動封面；舊版曾手動編輯且已有封面、或匯入的已有封面歌曲會保守略過。
- 搜尋受來源可用性和帳號權限影響，不保證每首歌曲都有封面。私人影片可能需要重新提供登入憑證。

Windows 未簽章免安裝包；Android 通用 Debug APK。擴充功能沒有修改。

技術來源：[yt-dlp 欄位與 YouTube Music 支援](https://github.com/yt-dlp/yt-dlp)、[Cover Art Archive API](https://musicbrainz.org/doc/Cover_Art_Archive/API)。
