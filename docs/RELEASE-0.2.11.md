# mp4/mp3 downloader 0.2.11

修正 Windows 標籤編輯的封面拖放與貼上：除了本機 PNG／JPEG 等圖片，現在亦能讀取 Chrome／Brave 傳送的圖片 HTML、圖片網址、虛擬圖片檔及 WebP 圖片。拖放到現有封面上會更新預覽；拖到編輯區其他位置亦會套用封面，不會被誤當成 MP3 匯入並清空歌曲選取。

封面仍然只在按下「儲存標籤」後寫入 MP3。載入失敗或逾時會保留目前封面及草稿；近正方形限制維持，不會自動拉伸或裁切圖片，也不會在下載資料夾另存 JPG。受網站保護、只提供網頁連結或瀏覽器沒有交出圖片的情況，可先另存圖片再拖入。

Android 在此版只同步版本號；本次封面拖放修正適用 Windows。可從 App 內檢查更新，下載紀錄與設定會保留。

已知環境問題：使用者回報 Surfshark 攔截 `Omni.NativeHost.exe`，可能影響瀏覽器擴充功能連接。本版保留已發布的 NativeHost；封面修正不會解除防毒攔截。若遇到此提示，先確認檔案來源、完整路徑及威脅名稱，再透過 Surfshark 官方支援核實。
