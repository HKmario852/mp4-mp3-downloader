# 0.2.13 驗證

Windows 資料夾匯入回歸測試通過：同一實體路徑的多筆下載紀錄及初始選取、正反斜線／`.`／大小寫路徑、資料夾與單一檔案重疊、重複及同時匯入，都維持一檔案一列。同名但不同檔案保留兩列；重新加入會刷新標題／演出者／專輯，保留既有紀錄 ID 及網址。檔案移動後舊列清理、匯入後儲存標籤均通過。

以使用者指定的資料夾進行唯讀驗證：329 個 MP3 連續匯入兩次仍為 329 個唯一檔案列；每個 MP3 匯入前後 SHA256 相同。測試亦確認匯入不寫入下載紀錄。已檢查一般視窗尺寸的 WPF 畫面截圖。

Windows Release App 建置通過。NativeHost 及下載引擎沿用 0.2.12 的未修改副本；未改動防毒設定。Android APK 建置及 22/22 單元測試通過；本版沒有改動 Android 匯入邏輯，未進行平板操作驗證。
