# mp4/mp3 downloader 0.2.17

修正 Windows 試聽播放器在切換頁面時停止的行為。歌曲現在會繼續播放，可自由前往新增下載、下載中、已下載、設定及 AcoustID 核對頁面。

返回「標籤編輯」會自動選取正在試聽的歌曲，沿用播放進度、音量及播放／暫停狀態，不會重新由開頭播放。保留彩色播放器圖示、靜音及可直接點擊／拖動的進度與音量控制。

播放器由主視窗持有，頁面只顯示控制項。選取另一首歌會結束上一首的試聽；正常離開頁面不會停止。真正關閉程式會釋放音訊。儲存／套用或復原正在播放檔案的標籤時，會先關閉該音訊以釋放 Windows 檔案鎖。

試聽及切换頁面不會改寫 MP3。保留資料夾來源保存及 AcoustID 的明確勾選、套用及復原流程。

Android 只同步版本號，本次播放行為修正針對 Windows。
