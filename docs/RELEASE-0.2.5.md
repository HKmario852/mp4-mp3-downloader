# mp4/mp3 downloader 0.2.5

- Windows／Android 新增完整 AcoustID 核對頁：使用同一應用程式視窗，隱藏普通側邊欄，保留原生視窗控制。
- 顯示候選錄音與專輯版本、AcoustID 指紋相似度、目前值／辨識結果比較，以及新舊封面。分數不是專輯版本或標籤準確率。
- 支援逐欄勾選、全選有變更、只填空白欄位、取消全選。未選欄位保持原樣，只有按「套用所選標籤」才寫入檔案；封面預設保留。
- 返回或取消保留標籤編輯草稿、選取、搜尋及捲動位置。套用後合併已寫入欄位與未套用草稿。
- 可保留完整 MP3 復原備份，返回編輯器後提供「復原上次套用」。如果檔案其後被修改，拒絕直接覆蓋。備份儲存在 App 資料目錄的 tag-undo。
- 修正歌曲標題包含 `< > /` 等字元時不能儲存的問題；這些限制只適用於選擇重新命名檔案時。
- 公開版本已配置本 App 的 AcoustID application key，無需每位使用者自行註冊。可在設定提供自己的 key；欄位遮蔽顯示，日誌不記錄原值。內建於本機應用程式的 application key 不具不可提取的保密性。
- 查找與寫入失敗會保留原資料並提供重試／返回操作；取消掃描會中止指紋程序及可取消的網絡請求。

已用 ENDROLL -HaThA- 驗證正式 AcoustID 查詢：指紋相似度約 99.39%，找到與 Picard 相同的錄音 ID 及兩個專輯版本。音訊檔案不會上傳，只傳送指紋與歌曲長度。

Windows 未簽章免安裝包；Android 通用 Debug APK。擴充功能沒有修改。
