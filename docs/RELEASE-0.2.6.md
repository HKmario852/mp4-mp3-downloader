# mp4/mp3 downloader 0.2.6

Windows 版改善貼上連結後的等待時間與 MP3 標籤處理方式。

- 分析連結所得的來源資料會在 10 分鐘內供同一連結的下載任務重用，避免按「開始下載」後再次分析。需要瀏覽器登入憑證的任務仍會自行分析，以免重用未授權的結果。
- 設定 → 格式新增「MP3 標籤與封面辨識時機」：預設「先完成下載，背景辨識」；可改為「下載時自動辨識，完成前等待」，或關閉自動辨識。舊版已啟用 MusicBrainz 的設定會轉為背景模式；已關閉的設定維持關閉。
- 背景模式會先將 MP3 放入「已完成」，然後再查 MusicBrainz／AcoustID 和近正方形封面。重新開啟 App 會繼續未完成的背景辨識。查詢失敗不會把已完成的下載標為失敗；手動改過的檔案不會被靜默覆蓋。
- 「下載診斷」增加來源分析、傳輸及轉檔、檔案處理的實際耗時，方便分辨 VPN／來源連線與本機處理。
- 目前 VPN 網絡下用公開影片測得首次來源分析 21.4 秒；同一連結進入下載任務時重用資料，分析僅約 0.0002 秒。另一條公開 YouTube 連結單次來源分析為 23.1 秒。這些結果不能單獨證明 VPN 是全部延遲的原因；VPN 分流設定需在 VPN 軟件內完成，App 內的「關閉代理」不會繞過系統 VPN。

Android 此版維持 0.2.5 功能，版本號同步至 0.2.6，方便兩平台使用同一公開更新頁。
