# mp4/mp3 downloader 0.2.15

Windows「標籤編輯」現在會記住「加入資料夾」及「加入 MP3」的來源。離開頁面再返回，或關閉並重開 App 後，會自動載入已加入的歌曲，不必每次重新選擇資料夾。

每次開啟標籤編輯都會讀取來源資料夾的實際 MP3，反映新增、移走及重新命名的檔案，並從原檔讀取最新標籤。重複加入或與下載紀錄重疊的檔案只會顯示一次；不同路徑的同名歌曲仍各自保留。個別無法讀取的檔案不會阻止其他歌曲載入；暫時找不到的來源會保留，下次再嘗試。

來源保存在 App 現有的本機資料庫，與下載紀錄及一般設定分開；記住來源不會改寫 MP3。單獨加入的 MP3 透過 App 重新命名後，保存的來源路徑亦會更新。

升級後請加入資料夾一次，開始保存來源。舊版只放在記憶體的加入清單無法在關閉後還原；未儲存的標籤修改仍按原有流程提示。

Android 本版只同步版本號；本次來源保存功能針對 Windows。
