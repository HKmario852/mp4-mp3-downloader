# mp4/mp3 downloader 0.2.14

Windows「標籤編輯」會顯示目前歌曲的完整檔案路徑；歌曲清單亦有檔案位置提示，方便區分不同資料夾的同名副本。讀取歌曲時，同步以實際 ID3 標籤刷新標題、演出者及專輯，避免繼續顯示下載紀錄的舊值。

修正部分舊 MP3 封面無法顯示的問題：APIC 圖片資料前多出的少量空 byte，在確認為 JPEG／PNG 圖片時可正確讀取；原有 frame 內容仍然保留，讀取及預覽不會改寫檔案。優先顯示正面封面；遇到損壞或不支援的封面，仍能正常顯示文字標籤，並清楚提示封面問題。

此版本不會從另一份同名歌曲自動覆寫標籤。不同資料夾內的檔案各自保留，只有按儲存標籤才會改動所選檔案。背景清單刷新亦保留未儲存的表單修改。

Android 本版只同步版本號；本次封面讀取及介面修正針對 Windows。
