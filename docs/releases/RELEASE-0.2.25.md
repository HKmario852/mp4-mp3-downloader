# Omni 0.2.25 — 來源音質同音質分析

- **顯示來源音質**：下載 MP3／音訊之後，「檔案詳情」會顯示 Omni 實際下載嘅音軌，例如「來源音質　Opus · 106 kbps · 48 kHz」。如果輸出位元率高過來源（例如 320 kbps 由 106 kbps 轉出），會提你音質以來源為準。舊紀錄冇呢項資料。
- **FLAC／WAV 標示更準確**：改為「無損格式（音質以來源為準）」——由有損音源轉出嘅 FLAC 唔會變返無損。
- **音質分析**：喺「標籤編輯」揀歌（最多 20 首），撳「音質分析」，Omni 會分析頻譜，估計真正嘅頻寬，標示「疑似假無損」（有損音源轉出嘅 FLAC）、「疑似升頻」（標示 320 kbps 但頻譜似 128 kbps）同取樣率過低嘅檔案。頻譜分析係推測，部分錄音本身冇高頻，結果只供參考。
- Android 版繼續用舊版相同金鑰簽署，可以直接蓋過 0.2.24 或更早版本安裝（0.2.21 除外）。

完整說明見 [CHANGELOG](https://github.com/HKmario852/mp4-mp3-downloader/blob/main/CHANGELOG.md)。
