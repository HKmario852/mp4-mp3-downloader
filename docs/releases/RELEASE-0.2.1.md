Windows / Android 介面及 MP3 標籤編輯更新。

- 已下載摘要加入綠色完成勾號、影片、音訊及檔案大小圖示；移除及常用操作加入圖示。
- 勾選框加大，統一為藍紫漸層、白色勾號及深色外框。搜尋列加入可見輸入提示。
- Windows 標籤編輯改為 App 內頁面；Android 加入標籤入口及完整編輯畫面。可加入 MP3 或遞迴加入資料夾、搜尋及多選歌曲。
- 編輯標題、演出者、專輯、專輯演出者、曲目、光碟、年份、類型、作曲者及註解；更多標籤可收合。只更新有改動欄位，批次音軌使用同一固定值。欄位旁的 × 可明確清空，包括多首歌曲原有值不同時。
- 封面更換／移除、音訊試聽與音量、復原變更、未儲存離頁提示。移除封面只移除歌曲內嵌圖片，不刪除可能由其他歌曲共用的外部 cover.jpg。
- 「同時重新命名檔案」預設不勾選；未勾選時只改標籤。MP3 下載預設檔名仍為歌曲名，MusicBrainz 設定及手動編輯保護保持不變。
- 設定頁隱藏主選單，提供返回按鈕。新增文字大小及介面大小（80–150%，預設 100%），儲存後套用。進階選項文字、滑桿及勾選框配合主題。

**更新方法**：設定 → 關於 → 下載並安裝最新版本；設定與歷史保留。

**Android 注意**：單一檔案授權不足以安全處理重名衝突時，需用「加入資料夾」取得父目錄權限後才可重新命名。外部儲存提供者仍可能拒絕寫入；畫面會顯示錯誤。匯入歌曲只加入本次編輯工作階段，不會當作新的下載紀錄。

Windows 仍未簽章，Android 仍是通用 Debug 測試 APK。瀏覽器擴充功能沿用原版，無需因本次介面更新而重新安裝。
