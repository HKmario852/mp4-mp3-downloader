# OMNI 0.2.22 — Android 可以再直接更新

- **修正 Android 無法更新**：0.2.21 嘅 Android APK 用咗新簽署金鑰，所以裝咗舊版嘅手機同平板 Android 會拒絕更新（「未安裝應用程式」）。0.2.22 改返用同舊版一樣嘅金鑰簽署，**可以直接蓋過 0.2.20 或更早版本安裝，App 內下載紀錄會保留**。仍然係正式（release）版本，執行速度同 0.2.21 一樣。
- 如果你已經裝咗 0.2.21，需要先解除安裝一次再裝 0.2.22（App 內更新會說明）。共用下載資料夾入面嘅檔案會保留。
- 其他功能同 0.2.21 一樣：yt-dlp 每日自動更新及「立即更新 yt-dlp」。Windows 版只更新版本號。

完整說明見 [CHANGELOG](https://github.com/HKmario852/mp4-mp3-downloader/blob/main/CHANGELOG.md)。
