# 0.2.14 驗證

Core 測試 81/81 通過。新增 APIC 測試涵蓋正常及 1／2／16 個空 byte 的 JPEG、Unicode 封面描述及 PNG、未知資料不會隨意截取、缺少終止符不會當成圖片。編輯文字後，未選取的 APIC frame 與音訊內容保持原樣。

Windows 回歸測試通過：從檔案讀取標籤取代過期清單資料；多餘空 byte 的封面可以預覽；損壞封面不阻止文字標籤顯示，也不殘留上一首歌曲的封面；完整來源路徑可見；背景刷新保留未儲存修改。

封面拖放／貼上回歸測試及 AcoustID 核對流程回歸測試通過，包含同視窗導航、取消保留草稿、只寫所選欄位、封面須明確選取、返回後保留未套用草稿及完整檔案復原。修正既有 Scan 測試的選取步驟，確保選取的歌曲與送交辨識的歌曲一致。

以兩個本機資料夾的同名 MP3 副本驗證：完整標籤副本正確顯示演出者、專輯、曲目及 500px 封面；資料較少的副本顯示自身原有標籤，並恢復封面預覽。兩份檔案仍可獨立選擇，測試前後 SHA256 及下載紀錄均相同。已檢查一般視窗尺寸的兩張 WPF 畫面截圖。

Windows Release App 已建置；NativeHost 與下載引擎沿用未修改的 0.2.13 副本，未修改防毒設定。Android APK 建置與 22/22 單元測試通過；未進行 Android 平板操作驗證。
