# Omni 0.2.23 — 清除單一紀錄及新名稱

- **清除所選紀錄**：喺「已下載」撳一個項目（或剔選多個）再按「清除所選紀錄」，只會清除嗰幾筆紀錄，實體檔案會保留。冇選取任何項目時按鈕會顯示「清除全部紀錄」，確認視窗亦會提示。顯示「檔案不存在」嘅紀錄而家都可以逐筆清除。
- **App 名稱改為 Omni**：視窗標題、左上角、系統匣、通知、Android 主畫面名稱及瀏覽器擴充功能都會顯示 Omni。
- Android 版繼續用舊版相同金鑰簽署，可直接蓋過 0.2.22 或更早版本安裝（0.2.21 除外）。

完整說明見 [CHANGELOG](https://github.com/HKmario852/mp4-mp3-downloader/blob/main/CHANGELOG.md)。
