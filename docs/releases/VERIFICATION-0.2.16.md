# 0.2.16 驗證

Windows 原生 MediaPlayer 測試使用隔離的靜音 MP3：確認真實播放、從音訊取得 20 秒時長、暫停時跳到 12 秒、音量直接由 100% 改為 50%、重新開啟音訊沿用所選音量、靜音／恢復、播放完畢重設，以及切換歌曲、下載、設定、AcoustID 頁面後關閉音訊與計時器。試聽前後測試 MP3 的 SHA256 不變。

Computer Use 實際操作隔離播放器視窗，使用 3 分鐘靜音 MP3：滑鼠點擊音量軌道由 100% 跳到顯示 50%，點擊進度跳到 1:33，暫停後拖動至 2:26。控制項數值及原生 MediaPlayer 播放位置一致；切到下載頁面後 Source 為空、播放狀態及計時器均停止。測試視窗已關閉，沒有操作或修改使用者目前開啟的 App 或歌曲。

已檢查正常及較窄視窗的 WPF 畫面，並以實際滑鼠操作確認彩色圖示、音量百分比、進度時間及焦點可辨識。

Core 84/84 測試通過；既有資料夾來源保存、跨程序重開及 AcoustID 核對流程回歸測試通過。

Windows 更新包沿用未修改的 NativeHost 與下載引擎；Windows Release 及 Android APK 建置成功；Android 22/22 單元測試通過。Android 只同步版本號，未進行平板操作驗證。
