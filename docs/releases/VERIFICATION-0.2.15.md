# 0.2.15 驗證

Core 84/84 測試通過。新增來源保存測試涵蓋重新建立 Store、Unicode 路徑、重複來源、空資料夾、子資料夾、新增／改名的歌曲、暫時消失後恢復的資料夾、個別無效標籤及單獨 MP3 改名。來源保存不改動歌曲 bytes，也不混入下載紀錄或偏好設定。

Windows 標籤編輯回歸測試通過：加入資料夾後切換下載頁面再返回，會恢復歌曲，反映新增及改名檔案；重複加入沒有重複歌曲。測試另外啟動全新的 Windows 程序，使用同一份測試資料庫，確認不再加入資料夾也能恢復清單；歌曲 SHA256 及下載紀錄保持原樣。

既有資料夾匯入／去重及 AcoustID 核對流程回歸測試通過。已檢查一般視窗尺寸的重開頁面 WPF 截圖，清單與編輯表單可正常顯示。

Windows 更新包沿用未修改的 NativeHost 及下載引擎，不變更防毒設定。Windows Release 建置及 Android APK 建置成功；Android 22/22 單元測試通過。Android 只同步版本，未進行平板操作驗證。
