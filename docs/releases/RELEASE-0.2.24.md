# Omni 0.2.24 — 下載 X（Twitter）年齡限制內容

- **X 年齡限制／敏感帖文可以下載**：喺「設定 › 網絡」匯入嘅 cookies.txt 以前只會用喺 YouTube。而家檔案入面有邊個網站嘅 Cookie，就會用喺嗰個網站，例如 X（x.com、twitter.com 都得）。Cookie 唔會傳去冇關嘅網站。
- **錯誤訊息更清楚**：遇到要登入先睇到嘅內容（例如 X 敏感帖文、私人帖文），會講明要用自己帳號匯出 Netscape cookies.txt，再喺設定匯入。
- 用法：用電腦瀏覽器登入 X，用 cookies.txt 擴充功能喺 x.com 匯出（如果同時要 YouTube，就兩個網站一齊匯出做同一個檔案），再喺 Omni「設定 › 網絡」揀呢個檔案並儲存。Cookie 等同你帳號嘅登入身份，請勿分享。
- Android 版繼續用舊版相同金鑰簽署，可以直接蓋過 0.2.23 或更早版本安裝（0.2.21 除外）。

完整說明見 [CHANGELOG](https://github.com/HKmario852/mp4-mp3-downloader/blob/main/CHANGELOG.md)。
