# MP4/MP3 downloader 0.2.16

Windows「標籤編輯」的試聽播放器加入播放／暫停狀態圖示、播放進度圖示、音量圖示與百分比。點擊喇叭可靜音，再點擊會恢復先前音量。

修正進度及音量滑桿只能逐格調整的問題：點擊軌道可直接跳到所選位置，亦支援拖動。進度使用音訊實際時長；暫停時跳播仍保持暫停。方向鍵可調整一秒進度或百分之一音量，滑桿有可見焦點及操作提示。

切換到下載、已下載、設定或 AcoustID 核對頁面，現在會明確停止試聽、關閉音訊及停止更新計時器；返回編輯不會自行繼續播放。切換歌曲、儲存標籤或頁面隱藏時亦會停止，播放完畢會重設按鈕與位置。

保留 0.2.15 的資料夾來源保存功能。試聽、調音量及跳播不會改寫歌曲或標籤。

Android 本版只同步版本號；本次播放器修正針對 Windows。
