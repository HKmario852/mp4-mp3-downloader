Windows 與 Android 的媒體庫及設定介面更新。

- 已下載：多選、縮圖、格式、畫質／音質、大小、完成時間、狀態、搜尋及格式／日期排序。Windows 加入檔案詳情側欄及分頁；Android 使用虛擬化清單。
- 每項檔案的「⋯」提供播放、檔案位置、重新命名、重新下載、檔案資訊、刪除。MP3 單曲及批次標籤編輯保留。
- Windows 刪除先確認並移至資源回收筒；Android 支援系統垃圾桶時交由系統確認，其餘位置會明確提示永久刪除。清除歷史不會刪除檔案。
- 設定改為 App 內的一般、下載、格式、網絡、通知、關於六個分類，提供深色／淺色／跟隨系統。儲存變更後生效；未儲存離頁會提示。
- 支援 1–10 個下載、獨立音訊／影片位置、限速及排程、代理、重試、重複檔案策略、命名範例、通知及勿擾時段。
- 提供 MP4／MKV／WebM 及 MP3／M4A／FLAC／WAV 選項、最高 4K、字幕及進階中繼資料設定。預設 MP3 檔名仍只有歌曲名，影片縮圖仍為預設第一封面。MusicBrainz 及手動編輯保護保留。
- 保留 Windows 擴充功能 ID 連接、GitHub 更新來源及 MusicBrainz 設定。更新仍由使用者確認後才安裝。

**更新方法**：0.1.4 使用者在現有設定內按「下載並安裝最新版本」。0.2.0 的相同功能在「設定 → 關於」。GitHub 專案填 `HKmario852/mp4-mp3-downloader`。不需要自行解壓；設定、Cookie 及歷史會保留。

**下載**：Windows 選 `OmniDownloader-windows-x64.zip`；Android 選 `OmniDownloader-universal-debug.apk`。瀏覽器擴充功能沿用 0.1.4，這次沒有更改登入傳送協定。

**使用限制**：影片編碼選項選取來源已提供的編碼，不會強制重編碼；WebM 需要相容来源，字幕嵌入建議用 MKV。部分格式或來源未提供足夠資料時，不顯示推測大小。FLAC／WAV 不能改善原本有損音源。MusicBrainz 只套用可靠匹配，並非每個 YouTube 影片都有歌曲資料。

Android 的開機選項提供繼續提示，不會繞過系統禁止開機啟動下載服務的限制。背景服務通知不能完全隱藏；完成後開啟檔案／資料夾只在 App 前景執行。SAF 提供者決定垃圾桶、目錄開啟及重新命名能力。Android 更新需確認系統安裝提示，必要時允許此 App 安裝更新。

Windows 仍未簽章；Android 仍為 Debug 測試 APK，未上架商店。英文介面保留部分中文診斷及進階標籤說明。來源及授權見 LICENSE、THIRD-PARTY.md；私隱說明見 docs/PRIVACY.md。
